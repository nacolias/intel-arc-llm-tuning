# Agent instructions

Read [`.agents/README.md`](.agents/README.md) before making any change. It covers where entries go, the evidence rules, and the pre-commit checklist.

This repository is public. Never commit IP addresses, hostnames, domains, API keys, tokens, secrets, `.env` files or their values, usernames, email addresses or serial numbers. Run `python3 .agents/scan-private-info.py` before every commit. Full rules are in [`.agents/privacy.md`](.agents/privacy.md).
