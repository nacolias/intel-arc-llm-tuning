# Templates

Copy a template into the right folder and rename it `YYYY-MM-DD-short-slug.md`.

| Template | Copy to | Use for |
|---|---|---|
| [`experiment.md`](experiment.md) | `models/<model>/experiments/` | one change attempt: hypothesis, exact change, result, decision |
| [`benchmark.md`](benchmark.md) | `models/<model>/benchmarks/` | one measured run of one configuration |
| [`research-note.md`](research-note.md) | `models/<model>/research/` | something you read and the claims it makes |
| [`finding.md`](finding.md) | `findings/` | a lesson that holds beyond one model |
| [`host.md`](host.md) | `hardware/hosts/` | one physical machine |

The environment table appears in several templates on purpose. Fill it in every time; it is what makes a result comparable months later.
