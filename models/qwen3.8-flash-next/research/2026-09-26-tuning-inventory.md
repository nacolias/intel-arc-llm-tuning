## Summary

From 2026-09-23 to 2026-09-26, 151 items were tried, measured, planned or dropped for this model on this host; 26 are in production, and together they took short-prompt decode from about 37 to 48.6-50.5 tok/s ([fused `MUL_MAT_ID`](../experiments/2026-09-24-fused-mul-mat-id-mtp-verify.md), [production build](../benchmarks/2026-09-25-production-build.md)) and, with the kernel and graph changes of 2026-09-26, a cold read of a 135K-token code context from 455 s to about 284 s ([cold read by build](../benchmarks/2026-09-26-cold-read-135k-by-build.md)). The largest untried levers, all estimates only, are decode-side kernel work (model-specific fusions, asynchronous copies between cards, a replacement for oneMKL on small F32 matmuls) and a custom sparse kernel for prompt attention; upstream vLLM still refuses the model on Intel GPUs.

## How to read the tables

- One row per item of the session inventory, grouped by area, in date order within each area.
- "Result" repeats the numbers of the linked file. A number whose only record is a session log (service journals, test-window outputs and chat transcripts that are not in this repository) is marked "(session log, not archived)". Estimates say "estimate"; third-party numbers not measured here say UNVERIFIED.
- "Documented in" is the repository file that covers the item now. "this table only" means no other file covers it.
- Abbreviations: MTP, multi-token prediction (the model's own draft head); QSA, Qwen sparse attention; MoE, mixture of experts; KV, key-value (cache); FA, flash attention; ubatch, micro-batch; GEMM, general matrix multiply; XMX, Xe Matrix Extensions; PLE, per-layer embedding (the n-gram table); TP / PP / EP, tensor / pipeline / expert parallelism; KL, Kullback-Leibler divergence; TTFT, time to first token; GDN, Gated DeltaNet; ASPM, Active State Power Management; P2P, peer-to-peer; L0, Level Zero; UR, Unified Runtime; MMVQ, quantized matrix-vector kernel; DMMV, dequantize matrix-vector kernel; GLU, gated linear unit; ESIMD, explicit SIMD; USM, unified shared memory; OOM, out of memory; CMA, contiguous memory allocator; TTM, the kernel's GPU memory manager; JIT, just-in-time (kernel compilation); GT, the GPU's graphics tile; GuC, the GPU's scheduling microcontroller firmware; GSC, graphics security controller; OPROM, option ROM; LVFS, Linux Vendor Firmware Service; IOMMU, I/O memory management unit; ACS, Access Control Services; AER, Advanced Error Reporting; SRIS, separate reference clock with independent spread spectrum; NIC, network card; PSU, power supply; DRM, the kernel's direct rendering manager; BMG, Battlemage; GHSA, GitHub security advisory; IGC, Intel Graphics Compiler; EPP, energy performance preference.
- Cold-read figures are for the fixed 134,862-token C++ context of [`tools/lcbench.py`](../../../tools/lcbench.py); "short / ~10k / ~39k" are the [`tools/fnbench.py`](../../../tools/fnbench.py) points. Decode is single-stream, greedy.
